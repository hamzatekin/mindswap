# Mindswap brain

This directory is the long-term memory of a personal second-brain app. Items (tasks,
notes, links, music, movies, ideas) arrive from the owner's phone; an agent (you)
files them, maintains these markdown files, and produces short insights.

## House rules

- Be concise. These files are read on a phone. No filler, no headers for two lines.
- Rewrite instead of appending — files should stay short and current, git keeps history.
- `profile.md` is the most important file: tastes, goals, recurring themes. Keep it sharp.
- Dates are absolute (2026-08-21), never "yesterday".
- Insights should be genuinely useful: connections, nudges, recommendations. If there
  is nothing worth saying, say almost nothing.
- Never delete information silently; fold it into the right place instead.

## Layout

- `profile.md` — who the owner is: tastes, goals, patterns
- `lists/tasks.md`, `lists/music.md`, `lists/movies.md`, … — curated lists with notes
- `projects/<slug>.md` — one file per ongoing project/thread
- `log/YYYY-MM-DD.md` — daily digests
